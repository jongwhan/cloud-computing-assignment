# 클라우드컴퓨팅실습 개인과제

## 프로젝트 소개

React 프론트엔드와 FastAPI 백엔드를 연동하고,
각각 Vercel과 Render에 배포한 개인과제입니다.

## 구성

- Frontend: React + Vite
- Backend: FastAPI
- Frontend 배포: Vercel
- Backend 배포: Render
- Source Code: GitHub

## 주요 기능

- 개인 소개 페이지
- React 프론트엔드에서 FastAPI API 호출
- FastAPI의 JSON 응답을 프론트엔드 화면에 표시
